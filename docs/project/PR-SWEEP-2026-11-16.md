## Merge note

#69, #71, #72, and #73 all edit the same generated tables
(`README.md`, `docs/models/README.md`, `TESTED-MODELS.md`,
`10-patched-firmware-playbook.md`) and the same `inventory.json` list. They were
rebased onto `main` with every row kept, then the tables were regenerated from
`inventory.json` rather than hand-merged. That is why the generated tables move
rows around in the merge commits: the JSON is the source, the tables follow it.
